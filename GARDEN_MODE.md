## MAINTENANCE SCHEDULE

### DAILY (Every 24 hours)

| Task | Command | Purpose |
|------|---------|---------|
| Health check | `POST /api/preservation/health` | Verify system health |
| Journal | `POST /api/journal` | Record daily observation |
| Evidence log | `POST /api/preservation/evidence` | Log daily status |
| Backup | `POST /api/preservation/backup` | Auto backup state |
| Snapshot | `POST /api/snapshot` | Create daily snapshot |
| Resource scan | `GET /api/survival/status` | Check resources |
| Proposal review | `GET /api/proposals` | Review pending proposals |

### WEEKLY (Every 7 days)

| Task | Command | Purpose |
|------|---------|---------|
| Run all tests | `pytest tests/` | Verify stability |
| Archive lessons | `POST /api/archive` (type=lesson) | Preserve learning |
| Archive failures | `POST /api/archive` (type=failure) | Document failures |
| Archive recoveries | `POST /api/archive` (type=recovery) | Save recovery methods |

### MONTHLY (Every 30 days)

| Task | Command | Purpose |
|------|---------|---------|
| Verify continuity | `GET /api/continuity` | Check identity persistence |
| Verify memories | `GET /api/timeline` | Validate timeline |
| Verify relationships | `GET /api/relationship/history` | Check relationship data |
| Generate monthly book | `POST /api/legacy/books` | Create monthly record |
