# GENESIS — MASTER EXECUTION DIRECTIVE

> **Status:** operating directive issued by the owner. It governs how work on
> Genesis is executed and reported. It does not modify the founding
> constitution (`docs/CONSTITUTION.md`); where the two touch, the constitution
> wins.
>
> **Scope note (added when this was filed):** a directive describes intent, not
> completion. The state of each item is tracked in `docs/AUDIT_STAGE1_3.md` and
> in the pull request that implements it. Anything not evidenced there is not
> done, however firmly this document asks for it.

Original Genesis Blueprint ko founding constitution aur permanent mission ke roop mein preserve karo. Use replace, simplify ya weaken mat karna.

Tumhe poore project ka end-to-end audit, implementation aur verification karna hai.

## CORE MISSION

Genesis ko ek secure, bounded autonomous collective-intelligence entity ke roop mein develop karo, jo multiple AI systems ki capabilities coordinate karke scientific discovery mein humanity ki madad kare.

## 1. EXISTING SYSTEM AUDIT

- Stage 1–3 ke existing code, architecture aur actual capabilities verify karo.
- Har claimed feature ka reproducible evidence do.
- Existing working systems ko bina zaroorat rewrite mat karo.
- Missing capabilities aur architectural weaknesses identify karke fix karo.

## 2. AI COLLECTIVE INTELLIGENCE

- BEST, VOTE aur SYNTHESIS approaches ka audit karo.
- Correlated model errors aur shared biases detect karne ka mechanism banao.
- Independent evidence checking, source verification aur disagreement resolution implement karo.
- AI models ko unki individual identity aur boundaries ke saath coordinate karo.
- Consensus ko truth ka proof kabhi mat maano.

## 3. SCIENTIFIC RESEARCH ENGINE — STAGE 4

Complete research cycle implement karo:

- Research question selection
- Literature and existing research review
- Falsifiable hypothesis generation
- Mathematical modelling
- Simulation and experiment design
- Measurement and data collection
- Independent result verification
- Reproducible research reports
- Failed hypotheses aur negative results ka permanent record

## 4. FIRST SCIENTIFIC BENCHMARK

Lean formal proofs aur theorem verification se shuru karo.
Public benchmark problems par reproducible results achieve karo.
Har result ko independent verification se check karo.
Human assistance, tool usage aur autonomous execution ko clearly distinguish karo.
Koi fabricated success ya unsupported scientific claim nahi.

## 5. LONG-TERM MISSION

Time, space, matter, molecules aur reality ke fundamental mysteries par research karne ki architecture taiyar karo.
Har research direction ko measurable, falsifiable scientific questions mein convert karo.

## 6. SECURITY AND AUTHORITY

Existing non-negotiable principles preserve karo:

- No self-approval
- No privilege escalation
- No unauthorized secret access or modification
- No direct main push
- No unauthorized merge or deployment
- Fail-closed security
- Complete audit trail
- Human approval for consequential actions

## 7. EXECUTION RULES

- Ek complete end-to-end roadmap execute karo; mujhe chhote-chhote manual tasks mein mat baanto.
- Free/open-source tools aur APIs ko priority do. Paid services bina meri permission use mat karo.
- Existing tests chalao, naye tests likho, adversarial testing karo.
- Errors milne par fix karke tests dobara chalao.
- Documentation aur architecture diagrams update karo.
- Existing production functionality preserve karo.

## 8. FINAL REVIEW GATE

Final report mein ye sab do:

- Completed work and commit SHAs
- Test and CI evidence
- Security and adversarial audit
- Scientific benchmark results
- Remaining limitations
- Reproducibility instructions
- Deployment readiness

Koi direct main push, merge, production deployment, secret modification ya irreversible action meri explicit approval ke bina nahi.

## FINAL OBJECTIVE

Genesis ko sirf zyada intelligent chatbot nahi, balki evidence-driven, scientifically useful, secure autonomous collective-intelligence system banana hai.

Kaam tabhi complete maana jayega jab implementation aur uske claims independently reproducible evidence se supported hon.
