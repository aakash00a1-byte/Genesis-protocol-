# Archived reports

These files were generated by Genesis/AI sessions during development. They are
historical snapshots, not current documentation: several describe a state of the
project that no longer matches the code (for example, an `src/` layout the repo
never used). They were moved here so the repository root shows only live
documentation, and kept — not deleted — so the history stays available.

For what is true right now, use:

- `README.md` — what the project is and how to run it
- `AGENTS.md` — how the system actually works (webhook, relay, work orders)
- `scripts/health_check.py` — run it to see what is live and what is broken
